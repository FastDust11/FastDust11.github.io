PRIVATE · NON-COMMERCIAL · PERSONAL USE

Encrypted backups for a personal TrueNAS server.

TrueNAS Backup is a private utility that allows its owner to store and restore encrypted backups of files from a self-hosted TrueNAS server in the owner's own Google Drive account.

This project is for its owner's personal use. It is not a public backup service and does not offer accounts or access to third parties.

What this application does

Back up selected files

The owner selects folders on a personally operated TrueNAS server to include in backup jobs.

Encrypt before upload

Restic encrypts backup data locally before it is transferred to cloud storage.

Manage backup history

Backrest manages scheduled backup jobs, retention and restoration. Rclone communicates with Google Drive.

Why Google Drive access is requested

Google OAuth authorization is used solely to create, read, update and delete the application's backup repository files in the owner's Google Drive account. The requested drive.file permission limits access to files used with this application. The app does not request access to Gmail, contacts, calendars or unrelated Google Drive files.

Backup contents are encrypted before upload. Google Drive stores the encrypted repository; it is not used to provide a public download or sharing service.

Privacy and security

This informational website has no login form, advertising, analytics scripts or tracking cookies added by its owner. OAuth credentials and repository encryption passwords are not entered into this website.

For details on how the backup utility accesses, stores, retains and deletes data, please read the Privacy Policy.
